MUHAMMAD MUJIB — PORTFOLIO

Files:
- index.html  : website structure and content
- style.css   : visual design, responsive layout, themes, and animations
- script.js   : theme switch, bilingual content, project detail modal, and button shine

How to use:
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Open index.html in a browser.

To edit:
- Personal text and sections: index.html
- Colors, spacing, and visual style: style.css
- Indonesian/English wording and interactions: script.js

Contact links are currently set to the email address and WhatsApp number supplied for this portfolio.
The project cards are marked IN DEVELOPMENT and do not contain repository/demo links yet.

Notes:
- Google Fonts requires an internet connection; the site falls back to system fonts if unavailable.
- Theme and language preferences are stored in the browser's localStorage.
- This is a static front-end website; no backend or database is required.
